# 客户端核心知识

按九个能力域组织 iOS 与 Android 的核心正文。学习主线是工程如何建立、代码和任务如何运行、状态如何形成交互、数据与系统能力如何协作，以及如何诊断、验证和交付。

- [iOS 核心正文](ios/README.md)
- [Android 核心正文](android/README.md)

本页集中维护文档职责和九篇正文的详细大纲。两个平台围绕共同问题，按各自机制分别编写；四个阶段控制学习深度，在同一套正文中持续完善。

## 各层文档的职责

内容按回答的问题划分职责。核心正文保留理解机制所需的前提、代码、场景与验证方法，各工程文档维护具体实现及操作入口。

| 位置 | 主要问题 | 内容职责 |
| --- | --- | --- |
| [根 README](../README.md) | 为什么建设仓库，如何学习 | 背景、目标、选型、目录入口与四阶段推进方式 |
| 本页 | 知识如何组织和阅读 | 九个能力域的关系、详细大纲与双端入口 |
| `docs/ios/`、`docs/android/` | 平台机制怎样工作，架构为何这样设计 | 原理、执行过程、职责边界、取舍、失败条件与验证方法 |
| `swift-core/docs/`、`kotlin-core/docs/` | 语言怎样表达，实验如何运行 | 语法、标准库、最小示例、编译器行为与实验说明 |
| `ios/docs/`、`android/docs/` | 当前工程怎样实现和验证 | 实现设计、源码位置、配置、API 用法、运行步骤与测量结果 |
| `shared/services/docs/` | mock 如何与客户端协作 | 接口契约、数据语义、场景控制、重置与复现方式 |

例如，同一个“任务取消”主题可以分别展开：

- 核心正文解释取消传播、协作式取消、资源清理，以及页面结束与业务任务结束的关系。
- 语言文档解释语法和 API，通过小实验观察行为。
- 工程文档解释当前请求由谁创建、何时取消、如何阻止迟到结果，以及怎样复现。
- 服务文档说明如何制造慢响应、连接断开等条件。

各层互相引用，并保留独立理解当前主题所需的必要说明。长期协作规则、任务流程与成果标准由根目录的 AGENTS、WORKFLOW、SPEC 分别维护。

### 01｜工程基础与工具链

主线：源码、依赖、资源和配置，如何形成可运行、可调试的应用。

- 工程的组成：应用目标、模块、源码、资源、测试与配置。
- 编译、链接、打包、安装、启动与调试各环节的职责。
- 依赖解析与集成：版本约束、锁定、传递依赖、源码与二进制依赖。
- 开发、测试和正式环境如何表达，配置怎样进入最终产物。
- 增量构建、缓存和代码生成，以及输入变化对结果的影响。
- 编译失败、链接失败、安装失败与运行失败的区分。

iOS 重点解释 Xcode 的 project、target、scheme、configuration 与 Swift Package 的关系；Android 重点解释 Gradle 的 project、module、plugin、task、variant 及工具版本关系。

具体安装步骤、版本选择、命令和当前工程配置放在平台工程文档。本篇解释工具链如何工作，第 09 篇解释如何利用工具链建立持续交付保障。

### 02｜语言、运行时与并发

主线：数据、对象和任务在客户端里如何执行、共享与结束。

- 类型、值、引用、可变性和相等语义对状态与数据建模的影响。
- 对象的持有与释放，闭包、回调和外部资源对寿命的影响。
- 同步、异步、并发和并行各自解决的问题。
- 线程、执行器和调度器如何承接任务，UI 更新受什么约束。
- 任务的父子关系、取消、超时、错误传播与清理。
- 共享状态的竞争、隔离与同步，持续数据流的消费、缓冲和结束。
- 串行、并发、后台执行与分批处理的选择条件。

iOS 重点是值与引用、ARC、捕获关系、Task、actor 隔离与重入；Android 重点是 JVM 对象与 GC、共享内存、协程作用域、Dispatcher、取消与 Flow。

具体语法和独立语言实验由两个 core 工程维护，本篇解释这些机制如何影响客户端运行与设计。

### 03｜应用宿主与生命周期

主线：应用、窗口、页面、业务对象和任务分别能存活多久。

- 从进程启动到可交互页面，系统与框架建立对象的过程。
- 应用、窗口、页面、UI 节点和业务状态的生命周期关系。
- 实例存在、页面可见、获得焦点与允许执行任务之间的区别。
- 前后台切换时，工作的暂停、继续与恢复。
- 系统重建、进程终止与重新进入后的状态存续。
- 状态保存、持久化和恢复各自承担的职责。
- 后台任务的执行机会、限制与可恢复设计。

iOS 围绕 App、Scene、视图与系统后台调度展开；Android 围绕 Application、Activity、导航目标、ViewModel、配置变化和进程重建展开。

本篇解释寿命、执行条件与恢复责任，系统能力的接入和调用边界由第 07 篇展开。

### 04｜UI、渲染与交互

主线：状态怎样成为画面，用户输入怎样推动新的状态。

- 声明式 UI 的描述、身份、依赖追踪与更新机制。
- 布局的尺寸测量与位置安排，绘制和呈现的衔接。
- 列表的按需创建、稳定身份、复用与滚动状态。
- 输入命中、手势竞争、焦点、键盘与表单编辑。
- 动画的时间、状态、布局与绘制成本，以及中断和恢复。
- 导航、模态界面和覆盖层中的页面关系。
- 自适应布局、主题、国际化、文字缩放与无障碍。

iOS 解释 SwiftUI 的身份、依赖与更新，以及必要的 UIKit 协作；Android 解释 Compose 的组合、状态读取、重组、布局与绘制阶段，以及 View 协作。

本篇聚焦 UI 机制和交互关系，跨框架嵌入中的线程、宿主与资源边界由第 07 篇展开。

### 05｜应用架构与状态组织

主线：系统增长后，如何保持职责清晰、依赖可控和状态可解释。

- 从变化原因划分 UI、业务逻辑、数据与平台能力。
- 页面、业务流程、账号和应用级状态的归属。
- 输入、状态迁移、副作用和 UI 反馈之间的数据流。
- 依赖的创建、注入、共享、替换与释放。
- 多页面共享资源、并行流程与一次性事件的组织。
- 模块边界、公开契约、依赖方向与循环依赖。
- 增加领域层、拆分模块或引入架构工具的条件。
- 通过可测试性和故障定位检验架构。

本篇讨论架构模式解决的问题、成立条件与代价。当前工程采用的目录、接口和具体实现设计放在平台工程文档中。

### 06｜数据访问与一致性

主线：外部数据如何进入客户端，成为可信状态，并在中断后恢复。

- 网络传输、序列化、数据模型与业务模型的边界。
- HTTP 请求、会话鉴权、错误分类、取消、超时与重试。
- WebSocket 的连接、订阅、消费者与重连恢复。
- 请求竞争、分页、快照与增量、顺序、重复和数据缺口。
- 内存、数据库、文件和网络缓存之间的关系。
- 存储选择、事务、结构迁移、容量与账号隔离。
- 离线编辑、同步、冲突、幂等和提交结果未知。
- 通过控制输入与完成顺序验证一致性和恢复。

接口字段、mock 控制方法由共享服务文档维护，当前客户端的数据层实现由平台工程文档维护。

### 07｜系统能力与互操作

主线：客户端如何跨越系统、框架和语言边界使用外部能力。

- 权限、能力声明、系统交互与用户授权的关系。
- 媒体、文件、认证、通知和深链的调用与结果模型。
- 外部 UI、宿主变化、取消与迟到回调。
- 系统后台调度接入应用架构的方式。
- WebView 与网页之间的会话、消息和信任边界。
- SwiftUI/UIKit、Compose/View 的嵌入与生命周期协作。
- C/C++、Flutter 插件等跨语言接入中的类型、线程、内存与错误契约。
- 真实系统行为及最终包中能力声明的验证。

具体能力按学习问题选择代表性实验，接入范围随实际需要展开。

### 08｜性能、稳定性与可观测性

主线：如何从用户现象找到运行原因，并验证治理效果。

- 体验问题与调度、计算、布局、绘制、I/O 和资源成本的对应。
- 启动阶段、关键依赖、首次显示与可交互时间的区别。
- 响应、滚动、动画和高频更新的分析方法。
- 内存、缓存、分配、泄漏、资源压力与能耗。
- 异常、崩溃、卡死、系统终止和恢复的不同边界。
- 日志、指标、事件、追踪与发生时上下文的协作。
- 诊断本身的采样、资源成本和信息裁剪。
- 受控对照的设计，以及收益、代价和结论适用范围的解释。

正文解释分析方法与机制，具体 trace、测量条件、工具步骤和修复结果放在工程文档中。

### 09｜质量、构建与交付

主线：如何持续验证变化，并让可靠、可追溯的产物到达设备。

- 按风险选择单元、UI、集成、契约与设备验证。
- 控制依赖、时间、数据和异步顺序，使验证可以重复。
- 静态检查、测试、构建和候选包验证形成的反馈链。
- 多环境、应用身份、版本、签名和能力配置的协作。
- 代码裁剪、混淆、资源、原生库和包体组成。
- 构建缓存、干净构建、输入版本和产物可追溯性。
- 符号、映射与异常堆栈还原。
- 发布后的观察、停止条件、兼容性和恢复策略。

本篇围绕变更验证与产物交付展开，工具链的基础运行关系由第 01 篇解释。
