## 学习起点与使用方式

已有 JavaScript、Dart 和 Flutter 复杂客户端经验，熟悉实时数据、请求竞争、导航、K 线视口、共享资源与构建交付。问题分析可以复用，Swift、Kotlin 和原生平台的身份、内存、任务、UI 与宿主语义分别核对。

开发时优先沿实际操作追踪状态、任务和数据：是谁接收输入，谁发起请求，哪个结果仍然有效，资源在什么条件下结束。遇到阻碍理解的问题可即时查阅官方资料或已有正文；应用形成后再沿下列能力域补齐知识。

九个能力域保持原编号，Android 内容较重的领域仍按现有 16 篇规划组织。它们是知识覆盖范围，不是功能清单、阶段关卡或第一版必须实现的全部能力。

## 推进策略与学习进度

当前产品、原型和接口方案等待学习者评估；两个原生目录仅有文档，尚未创建应用。平台正文入口说明已有内容，产品与实现状态分别由所属 README 和方案维护。

### 01｜语言、运行时与并发

主线：系统组织语言特性与执行机制，建立数据类型、空安全、内存、同步异步、线程、事件循环和并发的知识范围。

- 类型系统、基础类型、字符串、集合、空安全、控制流与模式匹配。
- 函数、闭包、类型定义、属性、初始化、协议、泛型、访问控制与错误处理。
- 值与引用、所有权、对象寿命、ARC／GC 与资源清理。
- 同步、异步、阻塞、挂起、并发与并行的区别。
- 进程、线程、队列、执行器／调度器、主线程与 UI 执行约束。
- 事件循环、事件源、定时器与平台调度机制；分别核对各平台模型。
- 任务作用域、结构化并发、取消、错误传播与结果汇合。
- 共享状态、隔离、同步、数据竞争、可重入性与异步数据流。

iOS 以 Swift 类型与 Optional、ARC、RunLoop、Task、executor、actor 和 Sendable 为重点；Android 拆为三篇：01-1 解释 Kotlin 的类型、空安全、类与函数的编译形态和 Java 互操作边界，01-2 解释 ART 的类加载、执行方式与 GC，01-3 解释 Looper／Handler、协程与 Flow。不能按术语相近推断调度语义一致。

### 02｜应用宿主与生命周期

主线：应用、窗口、页面、业务对象和任务分别能存活多久。

- 从进程启动到可交互页面，系统与框架建立对象的过程。
- 应用、窗口、页面、UI 节点和业务状态的生命周期关系。
- 实例存在、页面可见、获得焦点与允许执行任务之间的区别。
- 前后台切换时，工作的暂停、继续与恢复。
- 系统重建、进程终止与重新进入后的状态存续。
- 状态保存、持久化和恢复各自承担的职责。
- 后台任务的执行机会、限制与可恢复设计。

iOS 围绕 App、Scene、视图与系统后台调度展开；Android 拆为两篇：02-1 先解释 Zygote、system_server、AMS／ATMS、ActivityThread 与 Binder，说明组件生命周期由谁驱动；02-2 围绕 Application、Activity、Fragment、导航目标、ViewModel、配置变化和进程重建展开。

本篇解释寿命、执行条件与恢复责任，系统能力的接入和调用边界由第 06 篇展开。

### 03｜UI、渲染与交互

主线：状态怎样成为画面，用户输入怎样推动新的状态。

- 声明式 UI 的描述、身份、依赖追踪与更新机制。
- 布局的尺寸测量与位置安排，绘制和呈现的衔接。
- 列表的按需创建、稳定身份、复用与滚动状态。
- 输入命中、手势竞争、焦点、键盘与表单编辑。
- 动画的时间、状态、布局与绘制成本，以及中断和恢复。
- 导航、模态界面和覆盖层中的页面关系。
- 自适应布局、主题、国际化、文字缩放与无障碍。

iOS 解释 SwiftUI 的身份、依赖与更新，以及必要的 UIKit 协作；Android 拆为两篇：03-1 解释 Window、View 体系、Choreographer 与渲染管线以及事件分发，03-2 解释 Compose 的组合、状态读取、重组、布局与绘制阶段，以及与 View 的协作。

iOS 第 03 篇保留 SwiftUI 更新、布局、交互、导航、呈现与适配的机制解释；iPhone Duo 的区域能力作为版本专属专题。UI 路由与呈现规则由本篇解释，跨模块依赖与应用级流程组织在第 04 篇继续；具体实现和运行记录进入 iOS 工程文档。

本篇聚焦 UI 机制和交互关系，跨框架嵌入中的线程、宿主与资源边界由第 06 篇展开。

### 04｜应用架构与状态组织

主线：系统增长后，如何保持职责清晰、依赖可控和状态可解释。

- 从变化原因划分 UI、业务逻辑、数据与平台能力。
- 页面、业务流程、账号和应用级状态的归属。
- 输入、状态迁移、副作用和 UI 反馈之间的数据流。
- 依赖的创建、注入、共享、替换与释放。
- 多页面共享资源、并行流程与一次性事件的组织。
- 模块边界、公开契约、依赖方向与循环依赖。
- 增加领域层、拆分模块或引入架构工具的条件。
- 通过可测试性和故障定位检验架构。

本篇讨论架构模式解决的问题、成立条件与代价。当前工程采用的目录、接口和具体实现设计放在平台工程文档中。

### 05｜数据访问与一致性

主线：外部数据如何进入客户端，成为可信状态，并在中断后恢复。

- 网络传输、序列化、数据模型与业务模型的边界。
- HTTP 请求、会话鉴权、错误分类、取消、超时与重试。
- WebSocket 的连接、订阅、消费者与重连恢复。
- 请求竞争、分页、快照与增量、顺序、重复和数据缺口。
- 内存、数据库、文件和网络缓存之间的关系。
- 存储选择、事务、结构迁移、容量与账号隔离。
- 敏感数据与凭据的存储选择、备份与恢复边界，以及退出登录后的数据处置。
- 离线编辑、同步、冲突、幂等和提交结果未知。
- 通过控制输入与完成顺序验证一致性和恢复。

Android 拆为两篇：05-1 网络与实时数据，05-2 存储、缓存与离线。

接口字段、mock 控制方法由共享服务文档维护，当前客户端的数据层实现由平台工程文档维护。

数据保护与认证、存储和恢复机制结合学习，展开深度按当前场景确定。

### 06｜系统能力与互操作

主线：客户端如何跨越系统、框架和语言边界使用外部能力。

- 权限、能力声明、系统交互与用户授权的关系。
- 媒体、文件、认证、通知和深链的调用与结果模型。
- 外部 UI、宿主变化、取消与迟到回调。
- 系统后台调度接入应用架构的方式。
- WebView 与网页之间的会话、消息和信任边界。
- SwiftUI/UIKit、Compose/View 的嵌入与生命周期协作。
- C/C++、Flutter 插件等跨语言接入中的类型、线程、内存与错误契约。
- 真实系统行为及最终包中能力声明的验证。

具体能力随实际需求接入；WebView、额外权限、后台和混合开发属于后续扩展。Android 拆为两篇：06-1 系统能力与后台执行，06-2 跨语言与混合开发。

### 07｜工程基础与工具链

主线：源码、依赖、资源和配置，如何形成可运行、可调试的应用。

- 工程的组成：应用目标、模块、源码、资源、测试与配置。
- 编译、链接、打包、安装、启动与调试各环节的职责。
- 依赖解析与集成：版本约束、锁定、传递依赖、源码与二进制依赖。
- 开发、测试和正式环境如何表达，配置怎样进入最终产物。
- 增量构建、缓存和代码生成，以及输入变化对结果的影响。
- 编译失败、链接失败、安装失败与运行失败的区分。

iOS 重点解释 Xcode 的 project、target、scheme、configuration 与 Swift Package 的关系；Android 重点解释 Gradle 的 project、module、plugin、task、variant 及工具版本关系，并把完整的产物链放在本篇：Kotlin／Java 编译，D8／R8 的脱糖、裁剪、优化与混淆，AAPT2 资源编译，打包与对齐，v1–v4 签名，AAB，以及安装时的 dex2oat 和包体组成。

日常运行、日志、断点和构建配置切换按开发需要查阅工具教程，不必等到第 07 篇。具体安装步骤、版本选择、命令和当前工程配置放在平台工程文档。本篇解释工具链如何工作，第 09 篇解释如何利用工具链建立持续交付保障。

### 08｜性能、稳定性与可观测性

主线：如何从用户现象找到运行原因，并验证治理效果。

- 体验问题与调度、计算、布局、绘制、I/O 和资源成本的对应。
- 启动阶段、关键依赖、首次显示与可交互时间的区别。
- 响应、滚动、动画和高频更新的分析方法。
- 内存、缓存、分配、泄漏、资源压力与能耗。
- 异常、崩溃、卡死、系统终止和恢复的不同边界。
- 日志、指标、事件、追踪与发生时上下文的协作。
- 诊断本身的采样、资源成本、信息裁剪与敏感内容处理。
- 受控对照的设计，以及收益、代价和结论适用范围的解释。

Android 拆为两篇：08-1 性能方法、启动与流畅度，08-2 内存、ANR、崩溃与可观测性。

正文解释分析方法与机制，具体 trace、测量条件、工具步骤和修复结果放在工程文档中。

### 09｜质量、构建与交付

主线：如何持续验证变化，并让可靠、可追溯的产物到达设备。

- 按风险选择单元、UI、集成、契约与设备验证。
- 控制依赖、时间、数据和异步顺序，使验证可以重复。
- 静态检查、测试、构建和候选包验证形成的反馈链。
- 多环境、应用身份、版本、签名和能力配置的协作。
- 代码裁剪、混淆、资源、原生库和包体组成。
- 构建缓存、干净构建、输入版本和产物可追溯性。
- 符号、映射与异常堆栈还原。
- 发布后的观察、停止条件、兼容性和恢复策略。

本篇围绕变更验证与产物交付展开，工具链的基础运行关系由第 07 篇解释。Android 的裁剪、混淆、资源、原生库、签名与包体组成机制归入第 07 篇，本篇使用这些机制处理测试、CI、发布、灰度、回滚、mapping 还原、热修复与插件化、多渠道、隐私合规和 targetSdk 升级。
