# Android 知识正文

按[九个能力域与详细大纲](../README.md#九篇核心正文大纲)组织 Android 机制与架构参考，主线为 Kotlin + Jetpack Compose，必要时再补充 View 协作。内容较重的能力域保留 16 篇规划，编号用于知识归类。

## 使用方式

以股票 App 建立上下文，在需求开发与代码阅读中理解 Kotlin 和 Android；已有正文可随时回查，后续从实际问题反推完善。无需先完成全部正文，也不以模拟面试或独立语言实验作为推进条件。

当前保留 Kotlin 语言与编译模型正文，其他篇目是覆盖索引。产品和原型仍待评估，[Kotlin App 目录](../../kotlin-app/README.md)目前仅有环境与 Codex 配置文档，尚无原生工程。Android Studio 使用文档由学习者后续补充。

正文的成文、源码或产物核对、应用运行和学习理解分别表达。字节码、版本与资料的核对范围以各篇说明为准，不把正文存在视为原生工程已验证。
