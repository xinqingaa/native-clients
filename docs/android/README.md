# Android 核心正文

此目录按[九个能力域与详细大纲](../README.md#九篇核心正文大纲)组织 Android 原理、机制与架构正文，主线为 Kotlin + Jetpack Compose，并覆盖必要的 View 协作。

重点解释 Gradle 工具链、JVM 与协程、宿主生命周期与进程恢复、组合与渲染、状态与依赖、数据一致性、系统接入、诊断和交付。

具体语法与独立实验见 [Kotlin 语言文档](../../kotlin-core/docs/README.md)，当前应用实现与操作说明见 [Android 工程文档](../../android/docs/README.md)。正文将随对应学习主题逐步建立。
