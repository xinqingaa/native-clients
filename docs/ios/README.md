# iOS 核心正文

此目录按[九个能力域与详细大纲](../README.md#九篇核心正文大纲)组织 iOS 原理、机制与架构正文，主线为 Swift + SwiftUI，并覆盖必要的 UIKit 协作。

学习先从语言与执行开始，再进入宿主、UI、架构、数据和系统协作；第 07 篇系统学习工程工具链，第 08、09 篇进入诊断与交付。日常运行、日志和断点操作通过工程教程前置，不要求先读完构建机制。

每篇从具体问题和预期行为出发，解释本平台机制、适用条件与失败边界。语言写法见 [Swift 文档](../../swift-core/docs/README.md)，应用中的配置、操作和真实观察见 [iOS 工程文档](../../ios/docs/README.md)。

## 推进策略与学习进度

当前第一章以知识结构组织语言与执行机制，解释各主题的语义、关系和失败边界；swift-core 承接完整写法与独立实验，Xcode 教程与 EngineeringLab 提供应用操作和观察。第一章不以某个应用案例的执行步骤组织。

配套示例按集合、类型、协议和闭包，再到内存、错误与并发的顺序补充；不把“第一章”理解为第一次就完成全部并发学习。九篇编号组织知识，四阶段控制深度，学习顺序按先修关系调整。iOS 可与 Android 穿插，尚未建立的正文不生成空文件冒充成果。

任务交付、工程验证与学习掌握分别判断。能够运行项目只覆盖操作与部分行为；能解释数据怎样流动、预测修改影响并独立核对，才是当前学习目标的检验方式。
