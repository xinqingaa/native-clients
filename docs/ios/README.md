# iOS 核心正文

此目录按[九个能力域与详细大纲](../README.md#九篇核心正文大纲)组织 iOS 原理、机制与架构正文，主线为 Swift + SwiftUI，并覆盖必要的 UIKit 协作。

重点解释工具链、ARC 与并发隔离、应用与 Scene 生命周期、UI 身份与更新、状态与依赖、数据一致性、系统接入、诊断和交付。

每篇从具体背景、问题和预期行为出发，完整解释 iOS 的机制、保证与限制，再说明职责划分、设计取舍和验证方法。已有客户端经验用于确定起点，相关背景在本项目内说明；必要的 API 和短代码随解释保留。

具体语法与独立实验见 [Swift 语言文档](../../swift-core/docs/README.md)，当前应用实现与操作说明见 [iOS 工程文档](../../ios/docs/README.md)。正文与实验按学习主题逐步完善。

## 推进策略与学习进度

本页维护 iOS 的推进策略与当前进度，组织方式见[核心知识入口](../README.md#推进策略与学习进度)。主题按知识依赖和当前问题选择，可与 Android 穿插学习，Swift 独立实验与应用实践相互连接。

当前从第 01 篇建立运行模型，已形成工程基础正文与 EngineeringLab 最小工程。具体构建、调试和设备结果见工程说明；后续主题尚未建立。学习掌握需要结合学习者的解释、预测和操作检验。

- [iOS 工程入门](../../ios/docs/project-started.md)：创建、阅读、运行第一个 SwiftUI App，作为第一次接触 iOS 工程的操作入口。
- [01｜工程基础与工具链](01-engineering-foundations.md)：解释一次 Run 如何经过工程对象、构建阶段、安装、启动和调试；不替代入门操作。
- [EngineeringLab 实验](../../ios/docs/engineering-foundations.md)：六个学习单元、源码入口、运行步骤、截图与实际验证。

建议第一次学习时先完成 [iOS 工程入门](../../ios/docs/project-started.md)，再读 01 的整体关系和工程对象，随后打开 EngineeringLab 完成依赖、配置、增量与调试实验。已经熟悉 Xcode 时可以直接从 01 开始。02 以后按问题和先修关系推进。
