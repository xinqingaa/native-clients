# 海港视觉与交互语言

本文件维护两个原生 App 共同遵循的视觉与交互原则、设计 Token 和组件归类。产品行为见[产品方案](product.md)，可操作的样例见[交互原型](../prototype/README.md)，平台实现方式见[架构方案](architecture.md)。原型是本文件的参照实现，原生端按各自平台语义落地，不逐像素复刻 HTML。

## 基调

界面安静地承托任务，需要人做决定的地方才站出来。股票 App 信息量大，层级不靠容器和线条堆叠，而靠明度、字重、字号和留白分出主次。

两端采用同一套品牌视觉：颜色、字号阶梯、间距、卡片归类和动效语义一致。一级导航、弹层、返回手势和系统控件允许按平台习惯落地，例如 iOS 使用系统 TabView 的浮动形态，Android 自绘相同语义的浮动图标组。

## 五条判断

### 层级用明度，不用线条

页面使用三级明度：画布（bg）、凹陷填充（sunk，用于输入框、分段选择、次要按钮）、凸起表面（raised，只给卡片和导航选中项）。能用背景明暗和留白区分的，就不画分割线。列表行之间靠行高和间距分开，区块之间靠 28–32 的垂直间距和小号区块标题分开。

数字的主次由字号和字重决定：价格与总资产是一级，涨跌与盈亏是二级，标签与时间是三级灰。三级灰只用于说明性文字，不用于需要比较的数字。

### 卡片只给两类东西

卡片表示“需要你处理的”或“可以拿走的”。其余内容都是平铺的行。

| 类别 | 本应用中的内容 | 形态 |
| --- | --- | --- |
| 需要处理 | 进行中的委托（可撤单）、待确认的委托（15 秒有效期）、结果不明需恢复、行情断线、自选冲突、未登录时的关键提示 | 凸起卡片，带明确操作 |
| 可以拿走 | 委托回执、成交回执 | 凸起卡片，可关闭或跳转 |
| 平铺 | 自选、榜单、搜索结果、持仓、订单与成交记录、行情指标、盘口、资金分析、设置项 | 无容器的行或网格 |

### 能力回到发生的地方

信息出现在用户做这件事的位置，独立页面只做全局管理：

- 个股详情直接显示“持有 200 股”、当前浮盈和卖出入口，以及这只证券进行中的委托卡和最近一次成交回执。
- 自选行内用小字标出已持有，不需要切到账户核对。
- 成交在发起页面回流：委托卡就地变为成交回执，不依赖全局 Toast。
- 星标、排序、撤单在原处完成，结果由控件自身的变化说明，不再额外弹提示。
- 账户页负责资产全貌、全部持仓和订单历史；设置页负责身份、外观、涨跌色和规则。

### 动效回应操作

弹性、磁吸、拖拽、重排由用户动作触发，用来说明“什么变了、去了哪”：

| 操作 | 动效 |
| --- | --- |
| 切换一级入口 | 选中块滑到新图标，弹性收尾 |
| 进入详情 | 导航条在居中与靠左间过渡，交易按钮从右侧出现 |
| 打开交易弹层 | 自底部弹性升起，关闭时沿原路退回 |
| 管理自选 | 拖动手柄提起行，其余行让位，松手后磁吸到槽位 |
| 图表读数 | 十字线吸附到最近的 K 线 |
| 星标 | 图标轻微回弹 |

持续动画只留给正在执行的那一步：确认倒计时和撮合中委托的进度。报价变化只做一次短促的底色提示，不闪烁、不跳动。所有动效遵循系统的减弱动态效果设置。

### 一个状态只在一个地方说

| 状态 | 唯一位置 |
| --- | --- |
| 模拟交易身份 | 账户页身份行；规则详情在设置中 |
| 市场开闭与连接 | 市场页标题下方；断线时以卡片出现在当前页面顶部 |
| 单只报价新鲜度 | 个股详情价格下方的更新时间 |
| 委托进度 | 委托卡和订单详情时间线 |
| 冻结资金 | 账户页资金行 |

顶栏和标题不重复播报这些状态。

## 设计 Token

颜色按语义命名，浅色与深色各一套，跟随系统或由设置覆盖。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| bg | #F6F6F3 | #111214 | 页面画布 |
| sunk | #ECECE8 | #1C1D20 | 输入、分段、次要按钮填充 |
| raised | #FFFFFF | #26272A | 卡片、分段选中项 |
| pillOn | #FFFFFF | #3A3C41 | 一级导航选中块（深色下更亮，保证“亮色圆角”） |
| ink | #1C1E22 | #ECECEE | 一级文字与数字 |
| ink2 | #6A6D74 | #A0A2A8 | 二级文字 |
| ink3 | #9B9DA3 | #6E7076 | 标签、时间、单位 |
| accent | #3F6A9E | #8DB0DA | 链接、选中、主操作 |
| rise | #C2554B | #E07E73 | 上涨（随涨跌色设置交换） |
| fall | #2E8667 | #5DBA97 | 下跌（随涨跌色设置交换） |
| warn | #A9792F | #D5A55E | 倒计时、待处理提示 |

涨跌色是用户设置：红涨绿跌（默认）或绿涨红跌。界面只引用 rise/fall，切换时不改动组件。涨跌同时用正负号表达，不只依赖颜色。

| 维度 | 取值 |
| --- | --- |
| 字号 | 34 总资产与价格 / 28 一级标题 / 17 行主文字与数值 / 15 正文 / 13 次要 / 11 标签 |
| 数字 | 等宽数字（tabular），价格列右对齐 |
| 间距 | 4 的倍数；页面左右 20，行内上下 14，区块间 28–32 |
| 圆角 | 卡片 20，填充控件 12，胶囊 999 |
| 阴影 | 仅卡片和浮动导航使用一层很淡的阴影；深色模式靠明度区分，不用阴影 |
| 动效 | 弹性：阻尼约 0.8、时长约 0.4s；状态切换 0.2s 缓出；减弱动态效果时退化为淡入淡出 |

## 组件归类

| 组件 | 规则 |
| --- | --- |
| 一级导航 | 纯图标三个入口，半透明背景的浮动胶囊；选中项为 raised 圆角块加 accent 图标；详情页导航靠左，右侧出现交易按钮 |
| 页面标题 | 一级页面用大标题，右侧最多两个图标操作；二级页面用居中小标题和图标返回 |
| 行情行 | 名称与代码左侧上下排列，价格与涨跌右对齐；持有时代码旁标注“持” |
| 分段选择 | sunk 填充底，选中项 raised；用于周期、榜单、方向和范围 |
| 输入 | sunk 填充，无描边；聚焦时 accent 细环；数值输入带步进 |
| 主操作 | 实心胶囊，一个页面最多一个；买入/卖出使用 rise/fall |
| 委托卡 | 证券、方向、价格、数量、进度和撤单；撮合中显示进度 |
| 回执卡 | 结果、均价、费用，可关闭或查看订单 |
| 时间线 | 订单详情中按时间展示提交、受理、每次成交、撤单或完成 |

## 平台落地边界

本文件规定视觉语义，不规定实现 API。SwiftUI 优先使用系统 TabView、sheet 和材质，通过自定义颜色与字号贴合 Token；Android 以 XML/View 为主体，Compose 页面共用同一套颜色资源，具体方式见[架构方案](architecture.md)。系统材质、模糊和动效在不同系统版本上的表现需要在对应设备上验证，原型中的效果不代表原生端最终观感。
