# 模拟服务文档

维护服务运行方法、HTTP 接口契约、WebSocket 协议、固定数据、故障场景与重置方式。

协议说明需明确数据身份、顺序、错误和确认语义；实验场景需明确触发条件、客户端可观察结果与恢复方法。具体文档随 [服务实现](../src/README.md)逐步建立。

## Node.js 环境准备

开展共享 mock 实验时需要 Node.js。先检查已有环境：

```bash
node --version
npm --version
```

已有环境可用时，后续按服务工程声明的版本核对。尚未安装时，可从 [Node.js 官方下载页](https://nodejs.org/en/download)选择当前 LTS 的 macOS 安装包，手动完成安装后重新打开终端检查上述命令；已有版本管理器时使用原管理方式。

当前尚无 `package.json` 与服务实现，不需要现在执行依赖安装或启动命令。服务建立时再锁定 Node 版本、包管理方式和依赖锁文件，并补充实际安装、启动、重置与验证步骤。此处只提供环境准备说明，本轮未执行本机安装。
