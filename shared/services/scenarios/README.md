# 故障与恢复场景

当前可通过[原型](../../../prototype/README.md)和[接口](../docs/api.md)体验以下状态：休市/恢复交易、当前客户端暂停/恢复推送、未成交、部分成交、整单成交、撤单、确认过期、余额/持仓不足、自选版本冲突和账户重置。

部分成交来自每周期最多 100 股的模拟撮合；未成交可使用远离对手价的限价。确认过期通过等待 15 秒产生。市场切换作用于共享服务，推送暂停只作用于当前浏览器。

目前没有可配置的服务端网络延迟、乱序、丢回执或错误注入文件；提交结果恢复和重复请求由自动化行为检查覆盖。按实际产品需求再增加控制入口，避免预建独立实验场景库。
