# 海港移动交互原型

用于评估港股模拟交易 App 的页面、导航和操作反馈，界面方案仍可调整。产品范围与业务规则见[产品方案](../docs/product.md)，后续原生应用使用的协议见[接口方案](../shared/services/docs/api.md)。

## 打开方式

用浏览器直接打开 [index.html](index.html)，无需 npm、Node、构建或启动后端。也可以将本目录放在普通静态服务器下访问；从仓库根目录托管时，打开 `/prototype/index.html`。

样式、脚本、SVG 图表和样例数据全部在这一个 HTML 文件中，没有模块导入、接口请求、长连接、远程字体或 CDN。电脑中显示居中的手机预览，手机中使用当前视口，两种尺寸保持同一套移动页面。手机浏览器可通过已有静态托管方式访问。

## 页面与体验顺序

视觉与交互遵循[设计语言](../docs/design.md)：层级用明度不用线条，卡片只给需要处理的委托与可以拿走的回执，信息回到发生的位置，动效回应操作，一个状态只在一处表达。一级入口为“自选／市场／账户”，以纯图标浮动导航呈现；各入口保留自己的详情层级、筛选和滚动位置，再次点击当前图标回到该入口首页。详情页导航靠左，右侧出现“交易”；交易和登录使用可关闭的任务弹层。

1. 浏览自选，点股票进入详情，再切换市场或账户。切回来仍停在原来的页面，返回按钮沿当前入口回退。
2. 在自选底部卡片或账户选择“演示账户”，或用虚构邮箱注册本机账户。登录后自选行内标出已持有的证券；也可在修改自选或交易时登录，成功后继续原操作。
3. 搜索“网易”，用星标加入自选，星标就地回弹表示结果。打开右上角管理入口，拖动右侧手柄重排（键盘可用上下方向键），左侧移除，点击完成保存；直接返回放弃调整。
4. 在详情切换分时、日K、周K、月K，在图表上按住拖动查看读数，十字线吸附到最近的柱；“回到最新”结束查看。展开“资金分析”，切换今日、5 日、20 日。
5. 点“交易”，用步进按钮、对手价或常用数量填写。腾讯买入 430.00 HKD、100 股，核对页在倒计时圆环结束前提交，回执中的状态会实时变为已成交。
6. 回执中“完成”回到详情，价格下方出现持仓变化和成交回执，可收起或查看订单；“查看订单”转到账户中的对应委托，订单详情以时间线展示受理、每次成交和结束。
7. 在账户持仓点“卖出”，核对证券和方向；腾讯卖出价 427.00 HKD、100 股可观察成交，资金与持仓随之更新。
8. 腾讯买入设为 400.00 HKD、100 股，委托卡出现在详情和账户“进行中”；在卡片上撤单，卡片就地变为撤单回执，冻结资金释放。也可等待核对过期，返回填写页验证输入保留，再重新核对。
9. 在账户进入设置，切换主题（跟随系统、浅色、深色）与涨跌颜色（红涨绿跌、绿涨红跌），偏好保存在本机。

报价更新只刷新相关数字，列表价格短暂提示一次底色，不打断滚动位置和输入焦点。持续动画只用于确认倒计时和撮合中的委托。“模拟”身份只在账户身份行出现，市场开闭只在市场页标题下出现。

## 模拟数据边界

本文件在浏览器内模拟交互，不调用共享 Node mock。即使从共享服务的根路径打开，也不读取服务账户或订单，两套数据互不同步。

| 行为 | HTML 预览 |
| --- | --- |
| 账户 | 虚构邮箱、本机注册与登录；无服务凭据和刷新流程 |
| 自选 | 搜索、星标、管理草稿，完成后保存本机列表 |
| 行情 | 每 3 秒小幅变化；指数固定，图表和资金为合成快照；不模拟断线 |
| 图表 | 分时与 K 线、成交量、图面拖动与方向键十字线读数；捏合缩放、均线和历史分页尚未实现 |
| 交易 | 限价、每手 100 股、15 秒核对，每 1.5 秒每笔最多撮合 100 股 |
| 账本 | 整数分计算现金、冻结、成本和佣金；每笔累计成交额的 0.03%，最低 1 HKD |
| 市场时间 | 始终开市，不推进日终；委托保留到成交或撤销 |
| 页面隐藏或关闭 | 暂停行情与撮合，不补算离开期间的成交；重新打开后继续 |
| 重新加载 | 保留账户、自选、委托和成交；报价回到种子值，导航和未提交草稿重新开始 |

模拟账户资料和结果使用当前浏览器的 localStorage 保存（外观偏好单独保存），仅填写虚构资料。另一个虚构邮箱可用于从空持仓重新体验。同一文件在不同浏览器、文件位置、域名或端口打开时，记录可能独立。存储不可用时，当前页面仍可操作，关闭后不保留结果。

共享服务独立维护 HTTP、WebSocket、会话轮换、幂等、跨端版本冲突、日终和重启恢复；这些行为由[服务检查](../shared/services/README.md)和后续原生接入验证。

## 当前验证

2026-11-18 重做视觉层后，用 Playwright 驱动 Chromium 打开 `file://` 下的 index.html，自动执行并通过：

- 未登录交易先弹出登录，选择演示账户后继续进入交易。
- 腾讯 430.00 买入 100 股：核对、提交、回执状态实时变为已成交；完成后回到详情，持仓更新为 300 股并出现可收起的成交回执。
- 400.00 买入挂单：详情与账户出现委托卡，账户冻结 40,012.00 HKD；在卡片上撤单后冻结回到 0，卡片就地变为撤单回执。
- 持仓直接卖出带入证券与方向，427.00 卖出 100 股成交后持仓回到 200 股；订单详情时间线包含成交记录。
- 核对 15 秒过期后只能返回，返回填写页保留价格与数量；数量步进按一手增加。
- 自选管理拖拽重排后保存顺序；主题与涨跌色切换生效，刷新后保留。
- 320×568、390×844、430×932 下三个一级页面与详情无横向溢出，浮动导航与交易按钮不重叠；浅色与深色两套截图人工检查；控制台无 error / warn。

本轮未重新逐项执行旧版记录中的弹层焦点循环和浏览器返回键检查，相关逻辑沿用旧版实现，未作改动。iOS／Android 真机触摸、软键盘、安全区与系统材质效果仍待设备验证；原型中的模糊和弹性曲线只表达设计意图。
