# 海港移动交互原型

用于评估港股模拟交易 App 的页面、导航和操作反馈，界面方案仍可调整。产品范围与业务规则见[产品方案](../docs/product.md)，后续原生应用使用的协议见[接口方案](../shared/services/docs/api.md)。

## 打开方式

用浏览器直接打开 [index.html](index.html)，无需 npm、Node、构建或启动后端。也可以将本目录放在普通静态服务器下访问；从仓库根目录托管时，打开 `/prototype/index.html`。

样式、脚本、SVG 图表和样例数据全部在这一个 HTML 文件中，没有模块导入、接口请求、长连接、远程字体或 CDN。电脑中显示居中的手机预览，手机中使用当前视口，两种尺寸保持同一套移动页面。手机浏览器可通过已有静态托管方式访问。

## 页面与体验顺序

一级入口为“自选／市场／账户”：自选关注价格变化，市场用于发现股票，账户统一查看资产、持仓与订单。各入口保留自己的详情层级、筛选和滚动位置。详情保留底部导航，交易和登录使用可关闭的任务弹层。

1. 浏览自选，点股票进入详情，再切换市场或账户。切回来仍停在原来的页面，返回按钮沿当前入口回退。
2. 在账户选择“使用演示账户”，或用虚构邮箱注册本机账户。演示账户有三只持仓，新账户从空持仓开始；也可在修改自选或交易时登录，成功后继续原操作。
3. 搜索“网易”，用星标加入自选。返回后打开右上角管理入口，上移、下移或移除，点击完成保存；直接返回会放弃本次管理调整。
4. 在详情切换分时、日 K、周 K、月 K，通过滑块选取位置读取 OHLC；展开“资金分析”，切换今日、5 日、20 日。完整行情指标单独展开。
5. 点击详情底部“交易”，填写限价和数量。腾讯买入可填 430.00 HKD、100 股，核对后在 15 秒内提交，观察受理与成交反馈。
6. 反馈中的“完成”关闭交易并回到来源；“查看订单”明确转到账户中的对应委托。订单详情返回订单列表，再返回账户。
7. 在账户持仓直接点击“卖出”，核对证券和方向；腾讯卖出价 427.00 HKD、100 股可观察成交。资金、持仓与订单状态随成交更新。
8. 腾讯买入设为 400.00 HKD、100 股，观察待成交与资金冻结；在订单详情撤销，核对冻结释放。也可等待核对过期，返回填写页验证输入保留，再重新核对。

价格和涨跌、资产和可用资金分别使用明确层级；额外行情、资金明细和费用说明按需展开。报价更新只刷新相关数字，保持列表位置和输入焦点。账户设置只提供身份、模拟交易规则和退出入口。

## 模拟数据边界

本文件在浏览器内模拟交互，不调用共享 Node mock。即使从共享服务的根路径打开，也不读取服务账户或订单，两套数据互不同步。

| 行为 | HTML 预览 |
| --- | --- |
| 账户 | 虚构邮箱、本机注册与登录；无服务凭据和刷新流程 |
| 自选 | 搜索、星标、管理草稿，完成后保存本机列表 |
| 行情 | 每 3 秒小幅变化；指数固定，图表和资金为合成快照 |
| 图表 | 分时与 K 线、成交量、滑块与十字线读数；图面拖动、捏合、均线和分页尚未实现 |
| 交易 | 限价、每手 100 股、15 秒核对，每 1.5 秒每笔最多撮合 100 股 |
| 账本 | 整数分计算现金、冻结、成本和佣金；每笔累计成交额的 0.03%，最低 1 HKD |
| 市场时间 | 始终开市，不推进日终；委托保留到成交或撤销 |
| 页面隐藏或关闭 | 暂停行情与撮合，不补算离开期间的成交；重新打开后继续 |
| 重新加载 | 保留账户、自选、委托和成交；报价回到种子值，导航和未提交草稿重新开始 |

模拟账户资料和结果使用当前浏览器的 localStorage 保存，仅填写虚构资料。另一个虚构邮箱可用于从空持仓重新体验。同一文件在不同浏览器、文件位置、域名或端口打开时，记录可能独立。存储不可用时，当前页面仍可操作，关闭后不保留结果。

共享服务独立维护 HTTP、WebSocket、会话轮换、幂等、跨端版本冲突、日终和重启恢复；这些行为由[服务检查](../shared/services/README.md)和后续原生接入验证。

## 当前验证

2026-11-10，在 Codex 内置浏览器通过普通 Python 静态服务器访问 `/prototype/index.html`，实际完成：

- 三个入口的独立页面恢复，页面与浏览器返回，切换入口后保留图表周期、资金范围、展开状态和滚动位置。
- 登录取消、交易前登录后继续、注册虚构账户、退出、切回演示账户及重新加载；确认新账户无演示持仓。
- 搜索、星标、管理取消与排序保存；刷新后保留结果。
- 买入和持仓直接卖出各 100 股，核对订单状态、现金与持仓变化；低价挂单后撤销，确认冻结由 40,012.00 HKD 释放到 0。
- 数量校验、核对过期禁用提交、返回保留输入、重新核对提交；受理后分别完成返回来源、查看订单并逐级返回。
- 行情持续更新时保留价格、数量和焦点；弹层键盘焦点循环、关闭后返回操作入口。
- 320×568、390×844、430×932 手机视口与电脑默认视口。检查的页面无横向溢出，小屏详情和交易的底部按钮可见；浏览器控制台无 error / warn。

内联脚本语法检查通过，静态检查确认没有外部资源和网络调用依赖。共享服务 11 项自动化检查通过，覆盖的是服务实现。

自动浏览器工具禁止导航 `file://`，因此双击文件尚未实测；已验证自包含结构和普通静态托管下的交互。iOS／Android 真机触摸、软键盘和安全区行为仍待设备验证。
