# 海港可交互原型

当前原型用于产品评估，尚未获得最终确认。可以继续调整布局、交互和接口；本轮不据此建立原生工程。

HTML 原型与共享 Node mock 一起运行，使用真实 HTTP / WebSocket 调用。产品行为见[产品方案](../docs/product.md)，数据和接口见[接口方案](../shared/services/docs/api.md)。原型采用无构建步骤的 HTML、CSS、JavaScript，图表使用 Canvas，没有远程字体、图表 CDN 或图片依赖。

## 启动

在仓库根目录执行：

```bash
npm --prefix shared/services ci
npm --prefix shared/services start
```

打开 <http://127.0.0.1:4317>。需要 Node.js 22 或更新版本，实际核对为 Node.js 24.12.0。依赖安装只进入仓库的服务目录，不修改全局工具。

页面由共享服务提供，直接以 file URL 打开 index.html 不会运行接口。端口和数据位置配置见[服务说明](../shared/services/README.md)。

## 建议体验

1. 点击“登录 / 注册”，使用演示账户；也可以注册新模拟账户。
2. 搜索“网易”或 `09999`，星标加入自选；返回自选，使用上移和移除管理列表。
3. 打开腾讯，切换分时 / 日 K / 周 K / 月 K，拖动图表、缩放并加载更早行情；查看不同范围资金流向。
4. 买入 100 股。为便于观察成交，可以把限价设为略高于当前卖一价；在 15 秒内确认。
5. 在“交易委托 → 全部委托”和“成交明细”查看结果，再到“我的资产”核对现金与股数。
6. 从持仓卖出 100 股，限价略低于当前买一价，确认后核对持仓减少和现金增加。
7. 发起远低于当前行情的买单，在“当前委托”撤销，观察冻结释放。多手可成交委托每周期最多成交 100 股，可以观察部分成交。

演示设置位于桌面侧栏和账户菜单。可切换共享市场状态、暂停本客户端推送、恢复推送与重置当前账户；重置需连续两次点击确认。窄屏使用底部导航，选中自选后进入详情，交易面板在图表和资金流向下方。

## 当前实现与边界

登录、注册、自选修改、账户和交易均由服务保存；刷新页面不会清空业务数据。浏览器仅保存模拟会话和待确认提交标识。不同客户端登录同一账户读取相同数据。

模拟市场时钟与实际服务时间分别用于行情展示和确认倒计时。全部证券统一每手 100 股、简化佣金、合成行情及模拟成交规则见产品方案。周/月历史按固定时间桶合成，暂不代表自然周/月与真实交易日历。

原型不是原生平台行为证据。当前没有接入真实行情、券商、系统推送、后台能力或混合框架。

## 验证记录

2026-11-10，使用 Node.js 24.12.0 执行服务检查，11 项自动化测试全部通过；`node --check prototype/app.js` 和本次文档本地链接检查通过。

在 Codex 内置浏览器实际执行了：

- 演示登录、退出；注册独立模拟账户并自动登录，刷新后恢复会话，确认新账户没有演示持仓。
- 搜索网易、加入自选、上移、刷新后核对顺序、移除，列表由 6 只变为 7 只再恢复 6 只。
- 腾讯买入 100 股后查看成交与资金扣减、持仓增加；从持仓卖出 100 股后核对持仓减少。
- 提交远低于行情的买单、撤单，观察已撤单状态和冻结释放。
- 切换周 K、加载更早行情、切换 5 日资金流向。
- 暂停/恢复推送、切换休市并确认交易按钮禁用、恢复交易；服务重启后重新连接。
- 1440×1000 宽屏与 390×844 手机视口检查，页面主体没有横向溢出；资产/委托的宽表格在容器内横向滚动。最终浏览器控制台没有 error/warn。
